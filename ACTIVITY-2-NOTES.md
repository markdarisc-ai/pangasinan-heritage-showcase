# Activity 2 — Student Notes

This project is based directly on the Activity 1.1 source code.

## What was completed in the project

1. Static export is enabled in `next.config.mjs`.
2. GitHub Pages project-path support is configured for `/pangasinan-heritage-showcase`.
3. Static heritage detail routes are generated with `generateStaticParams()`.
4. Activity 1.1 Atomic Design components remain in use.
5. Metadata was added to the main pages for SEO.
6. A robots route was added.
7. Interactive links were made accessible without nesting `<button>` inside `<a>`.
8. Images remain lightweight SVG assets and use asynchronous decoding.
9. A GitHub Actions workflow was added for automatic GitHub Pages deployment.
10. README contains the Activity 2 requirements, deployment instructions, Lighthouse targets, and submission checklist.

## What still requires the student's GitHub account

The assistant cannot create/push to the student's GitHub account or produce the real public GitHub Pages URL without access to that account.

After creating the public repository named `pangasinan-heritage-showcase`, push this project to the `main` branch. The included workflow will build and deploy the static site.

Then run the Lighthouse audit on the live URL and save the results. The final scores cannot be truthfully filled in until the live website has been tested in Chrome.
